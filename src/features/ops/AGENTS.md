# Ops screens rules

- Lists that can exceed 1000 rows load via `fetchAll` paging in OpsContext (API caps 1000 rows).
- Roster, Sign-in desk and Variations link via one-shot query params (`/admin/roster?shift=|view=`, `/admin/sign-in?slot=`, `/admin/variations?shift=|open=|status=`) read once on mount then cleared; `?open=` waits for variations to load and switches to the variation's event. Pages an account can't open show a "signed in as… switch account" notice instead of redirecting (guard-only accounts go to `/mobile`). Roster tabs and Dashboard tiles share `matchesRosterView`.
- Guard QR passes are `GUARDPASS:<guard id>` (`QrScanner.tsx`); the Sign-in desk (`SignIn.tsx`) reads them from the camera or from keyboard-wedge desk scanners (`useHardwareScanner`, fast keystroke burst + Enter, works without focus), then still calls `manager_sign_on`.
- Costs UI gates on `showCosts` from OpsContext; view_* permissions gate pages via `can()`.
- User guides are typed content in `guides/` (`adminGuide.ts`, `securityManagerGuide.ts`, shared topics in `shared.ts`), rendered and searched client-side by `Guides.tsx` at `/admin/guides` (open to every user type; security-only users see just the Security Manager guide). Update the guide content whenever a feature changes.
- Communications and Settings → Events → SMS integration call SMS edge functions through `invokeFunction` (OpsContext); the app never talks to Tall Bob or reads credentials.
- Live Map (`LiveMap.tsx`, embedded at the bottom of the Dashboard for `view_locations` users; `/admin/live-map` redirects there) and guard sharing (`GuardLocation.tsx`) use freshness/cutoff rules in `src/lib/location.ts`; the map reads `guard_latest_locations` (RLS-scoped) and refetches on every realtime (re)connect.
- Native guard app is Capacitor (`capacitor.config.ts`, `android/`, `ios/`; loads the live `/mobile` portal, location permissions in AndroidManifest/Info.plist; Android uses a location foreground service, never ACCESS_BACKGROUND_LOCATION, so Play needs no background-location declaration; `useLegacyBridge` + CapacitorHttp keep locked-screen uploads flowing); `GuardLocation.tsx` uses `@capacitor-community/background-geolocation` when `Capacitor.isNativePlatform()` (locked-screen sharing with an OS notification), browser `watchPosition` otherwise — same RPCs, consent and cutoff for both.
- Public privacy policy is `PrivacyPolicy.tsx` at `/privacy` (no login; store listings link to it). Update it whenever collected data, recipients or location behaviour change.
- Guards delete their own account only via the `delete-my-account` edge function (Profile tab; refused while signed on, mirrors `canDeleteOwnAccount`): deletes login/profile/roles/location/group rows and blanks contact+licence, but keeps the suspended guard row because attendance references it.
